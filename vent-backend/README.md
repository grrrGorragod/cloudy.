# vent-backend

หลังบ้านของเว็บระบายความรู้สึกแบบนิรนาม ใช้ Node.js (JavaScript ล้วน ไม่มี TypeScript) + Express + Postgres

## รันในเครื่อง

```bash
npm install
cp .env.example .env     # แล้วแก้ค่า DATABASE_URL, OPENAI_API_KEY
npm run dev
```

ตารางในฐานข้อมูลจะถูกสร้างอัตโนมัติตอนเซิร์ฟเวอร์เริ่มทำงาน (`schema.sql`)

## ขึ้น Render + Neon

1. สร้างฐานข้อมูลบน Neon แล้วคัดลอก connection string มาใส่ `DATABASE_URL`
2. สร้าง Web Service บน Render ชี้ไปที่โฟลเดอร์นี้
   - Build command: `npm install`
   - Start command: `npm start`
3. ตั้ง Environment ใน Render: `DATABASE_URL`, `OPENAI_API_KEY`, `CORS_ORIGINS` (โดเมนหน้าเว็บจริง)
4. โทเคน OpenAI อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ห้ามใส่ในโค้ดหน้าเว็บ

## วิธียืนยันตัวตน

ไม่มีล็อกอิน หน้าเว็บสร้างกุญแจสุ่มเองแล้วส่งทุก request ใน header

```
Authorization: Bearer <key>
```

เซิร์ฟเวอร์เก็บเฉพาะ SHA-256 ของกุญแจ ไม่เก็บกุญแจจริง

**กุญแจต้องสุ่มให้ได้ประมาณ 128 บิตขึ้นไป** (เช่น base32 26 ตัวอักษร ใช้ `crypto.getRandomValues` ของ browser) กุญแจแบบ 6 คำจากรายการสั้นๆ ในต้นแบบหน้าเว็บ **อ่อนเกินไปสำหรับของจริง** ต้องเปลี่ยนตอนเชื่อมหน้าเว็บ

## API

| Method | Path | ใช้ทำอะไร |
|---|---|---|
| GET | `/api/config` | อายุโพสที่เลือกได้ ข้อความสำเร็จรูป สายด่วน |
| POST | `/api/register` | ตั้งชื่อครั้งเดียว `{name}` ได้ชื่อพร้อมรหัสท้าย เช่น `ดาว#4821` เปลี่ยนไม่ได้ |
| GET | `/api/me` | ใส่กุญแจเดิมตอนย้ายเครื่อง ได้ชื่อเดิมกลับมา (401 ถ้ากุญแจไม่ถูก) |
| GET | `/api/posts` | โพสที่ยังไม่หมดอายุ ใหม่สุดก่อน (สูงสุด 60) |
| GET | `/api/posts/:id` | โพสพร้อมคำตอบ (มี `owner: true` ที่คำตอบของเจ้าของโพส) |
| POST | `/api/posts` | `{text, days: 1/3/7/14, mode: "free"/"reactions"}` |
| DELETE | `/api/posts/:id` | เจ้าของลบโพสตัวเอง |
| POST | `/api/posts/:id/replies` | `{text}` หรือ `{preset: 0-3}` เจ้าของโพสใส่ `toReplyId` เพื่อตอบกลับข้อความของคนอื่นได้ |
| DELETE | `/api/replies/:id` | ลบคำตอบของตัวเอง |
| POST | `/api/posts/:id/care` | กด/ยกเลิกห่วงใย (สลับค่า) |
| POST | `/api/reports` | `{postId}` หรือ `{replyId}` ถูกรายงานครบ 3 คนจะซ่อนอัตโนมัติ |

ข้อผิดพลาดที่หน้าเว็บควรจัดการ: `422 blocked` (มี `message` ภาษาไทยให้แสดงได้เลย), `503 moderation_unavailable` (ให้ผู้ใช้กดส่งใหม่ และเก็บข้อความไว้ในช่องพิมพ์), `429` (โพสหรือตอบเยอะเกิน)

## การตรวจข้อความ (moderation)

ดูที่ `src/moderation.js` มี 2 ชั้น

1. **ตรวจในเครื่อง:** บล็อกเบอร์โทร อีเมล เลขบัตรประชาชน ไอดีโซเชียล (LINE/IG/Facebook ฯลฯ และ @ชื่อ) ลิงก์ และตัวอักษรซ้ำรัวๆ
2. **OpenAI Moderation API:** แยกเป็น 3 ระดับ
   - *บล็อก:* การด่า/คุกคาม/เกลียดชัง/ข่มขู่ผู้อื่น (โพสไม่ลง พร้อมข้อความอธิบาย)
   - *ผ่านพร้อมคำเตือนเนื้อหา:* เรื่องเพศ ความรุนแรง หรือการทำร้ายตัวเอง (เช่น เล่าว่าถูกข่มขืนยังโพสได้) ได้ค่า `warn: true`
   - *ผ่านพร้อมข้อมูลช่วยเหลือ:* สัญญาณว่าอยากทำร้ายตัวเอง โพสยังผ่านตามปกติ แต่ response ของ `POST /api/posts` จะมี `support: true` ให้หน้าเว็บแสดงข้อความอ่อนโยนและเบอร์ 1323

ข้อควรรู้

- ค่าเกณฑ์เป็นจุดเริ่มต้น **ต้องทดสอบกับข้อความภาษาไทยจริง** แล้วปรับผ่าน `MOD_THRESHOLDS` ตัวตรวจอาจพลาดคำแสลง และบางครั้งอาจมองว่าการด่าตัวเองเป็นการด่าคนอื่น
- ถ้าเรียก OpenAI ไม่สำเร็จ ระบบจะ **ไม่ปล่อยผ่าน** แต่ตอบ 503 ให้ลองใหม่ (ปลอดภัยกว่า แต่ถ้า OpenAI ล่มนานผู้ใช้จะโพสไม่ได้)
- ข้อความที่ส่งตรวจจะถูกส่งไปให้ OpenAI ควรบอกผู้ใช้ในนโยบายความเป็นส่วนตัว
- ข้อความสำเร็จรูปไม่ผ่านการตรวจ เพราะเซิร์ฟเวอร์เป็นคนกำหนดเอง

## ความเป็นส่วนตัว

- ไม่เก็บ IP ในฐานข้อมูล (rate limit ใช้หน่วยความจำ) และไม่ log เนื้อหาข้อความ
- โพสหมดอายุถูกลบจริงทุก 30 นาที พร้อมคำตอบ ห่วงใย และรายงานที่ผูกกับโพสนั้น
- แถวผู้ใช้ (ชื่อ + hash กุญแจ) ยังอยู่ต่อแม้โพสหมดอายุ ควรกำหนดนโยบายลบบัญชีที่ไม่ได้ใช้นานๆ ในภายหลัง

## เฝ้าดูว่าเว็บล่มไหม

`GET /healthz` ตอบ 200 เมื่อเซิร์ฟเวอร์และฐานข้อมูลปกติ และ 503 เมื่อฐานข้อมูลไม่ตอบ ให้บริการเฝ้าเว็บฟรี (เช่น UptimeRobot) ยิง `https://<backend ของคุณ>/healthz` ทุก 5 นาที แล้วตั้งให้ส่งอีเมลเมื่อล่ม

## แอดมิน (บรรทัดคำสั่ง)

รันในเครื่องคุณเอง ไม่มีหน้าเว็บให้ใครโจมตี ต้องมี `DATABASE_URL` ใน `.env` ชี้ไปฐานข้อมูลที่ต้องการดูแล

```bash
npm run admin -- reports                 # ดูรายการที่ถูกรายงาน/ซ่อนอยู่
npm run admin -- show post 12            # ดูเนื้อหาเต็มและเหตุผลที่ถูกรายงาน
npm run admin -- approve post 12         # เลิกซ่อน และไม่ซ่อนซ้ำจากรายงานเพิ่ม
npm run admin -- hide reply 7
npm run admin -- delete post 12
npm run admin -- delete-user "ดาว#4821" --yes   # ลบบัญชีและเนื้อหาทั้งหมด (ผู้ละเมิด/คำขอลบข้อมูล)
```

## กันรายงานกลั่นแกล้ง

- บัญชีที่อายุไม่ถึง `REPORT_MIN_ACCOUNT_HOURS` (ค่าเริ่มต้น 24 ชั่วโมง) รายงานไม่ได้
- รายงานได้ไม่เกิน `REPORT_MAX_PER_DAY` (ค่าเริ่มต้น 10) ต่อบัญชีต่อวัน
- รายงานข้อความของตัวเองไม่ได้
- ครบ `REPORT_HIDE_AT` (ค่าเริ่มต้น 3) จะซ่อนอัตโนมัติ แต่ถ้าแอดมิน `approve` แล้ว จะไม่ถูกซ่อนซ้ำ
