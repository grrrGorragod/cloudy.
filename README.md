# cloudy.

> บางสิ่งที่อยู่ในใจ อาจเบาลงเมื่อเราได้พูดมันออกมา

**cloudy.** คือพื้นที่ระบายความรู้สึกแบบนิรนาม เขียนสิ่งที่อยู่ในใจแล้วปล่อยให้ลอยขึ้นฟ้าเป็นโคม คนอื่นอ่านและส่งกำลังใจกลับมาได้ โดยไม่ต้องล็อกอินและไม่ต้องใช้ชื่อจริง

🔗 **เว็บจริง:** https://cloudy-5n1s.onrender.com/

## ฟีเจอร์

- **ไม่ต้องล็อกอิน** ตั้งชื่อครั้งเดียวแล้วได้ชื่อพร้อมรหัสท้าย เช่น `ดาว#4821` ระบบสร้างกุญแจสุ่มไว้ในเบราว์เซอร์ และใส่กุญแจเดิมเพื่อย้ายเครื่องได้
- **โพสหมดอายุเอง** เลือกอายุโพสได้ 1 / 3 / 7 / 14 วัน เมื่อหมดอายุจะถูกลบจริงพร้อมคำตอบและปุ่มห่วงใย
- **ท้องฟ้าโคม** โพสแต่ละอันแสดงเป็นโคมลอยบนท้องฟ้า
- **ตอบและห่วงใย** ตอบโพสได้ กดปุ่มห่วงใย หรือเลือกข้อความสำเร็จรูป
- **ระบบตรวจข้อความ** บล็อกข้อมูลส่วนตัว (เบอร์โทร อีเมล ไอดีโซเชียล ลิงก์) และการด่า/คุกคาม ส่วนเนื้อหาอ่อนไหวผ่านได้พร้อมคำเตือน
- **ข้อมูลช่วยเหลือ** ถ้าข้อความมีสัญญาณอยากทำร้ายตัวเอง จะแสดงข้อความอ่อนโยนและเบอร์สายด่วนสุขภาพจิต 1323
- **รายงานและซ่อนอัตโนมัติ** ถูกรายงานครบ 3 คนจะซ่อนทันที พร้อมแจ้งแอดมินผ่าน Discord

## รันในเครื่อง

ต้องมี Node.js 20 ขึ้นไป และฐานข้อมูล PostgreSQL (เช่น สร้างฟรีบน [Neon](https://neon.tech))

**1. หลังบ้าน**

```bash
cd vent-backend
npm install
cp .env.example .env     # แล้วแก้ค่าใน .env
npm run dev              # รันที่พอร์ต 3000
```

ตารางในฐานข้อมูลจะถูกสร้างอัตโนมัติตอนเซิร์ฟเวอร์เริ่มทำงาน

**2. หน้าเว็บ** (เปิดอีกเทอร์มินัล)

```bash
cd vent-frontend
npm install
npm run dev              # เปิด http://localhost:5173
```

ตอนพัฒนา การเรียก `/api` จะผ่าน proxy ไปที่หลังบ้านในเครื่องอัตโนมัติ

## ตัวแปรสภาพแวดล้อม

**หลังบ้าน** (`vent-backend/.env`)

| ตัวแปร | จำเป็น | คำอธิบาย |
|---|---|---|
| `DATABASE_URL` | ✅ | connection string ของ PostgreSQL |
| `OPENAI_API_KEY` | ✅ | คีย์สำหรับ Moderation API (อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น) |
| `CORS_ORIGINS` | ✅ | โดเมนหน้าเว็บที่เรียก API ได้ คั่นด้วยจุลภาค |
| `DISCORD_WEBHOOK_URL` | | แจ้งแอดมินเมื่อมีโพสถูกซ่อนอัตโนมัติ |
| `MOD_THRESHOLDS` | | ปรับเกณฑ์ตรวจข้อความ (JSON) |
| `PORT` | | ค่าเริ่มต้น 3000 |

ดูตัวแปรอื่นๆ ที่ปรับได้ใน `vent-backend/.env.example`

**หน้าเว็บ** (ตอน build)

| ตัวแปร | คำอธิบาย |
|---|---|
| `VITE_API_URL` | URL ของหลังบ้าน เช่น `https://<ชื่อบริการ>.onrender.com` (ไม่มี `/` ท้าย) |

> ⚠️ **ห้ามนำไฟล์ `.env` ขึ้น git** ไฟล์เหล่านี้อยู่ใน `.gitignore` แล้ว

## ขึ้นเว็บจริง

1. **ฐานข้อมูล:** สร้างบน Neon แล้วคัดลอก connection string
2. **หลังบ้าน:** สร้าง Web Service บน Render
   - Root Directory: `vent-backend`
   - Build: `npm install` / Start: `npm start`
   - Health Check Path: `/healthz`
   - ตั้งตัวแปรสภาพแวดล้อมตามตารางด้านบน
3. **หน้าเว็บ:** สร้าง Static Site บน Render
   - Root Directory: `vent-frontend`
   - Build: `npm install && npm run build` / Publish Directory: `dist`
   - ตั้ง `VITE_API_URL` เป็น URL ของหลังบ้าน
4. กลับไปตั้ง `CORS_ORIGINS` ที่หลังบ้านให้ตรงกับ URL ของหน้าเว็บ

## ความเป็นส่วนตัว

- ไม่เก็บ IP ในฐานข้อมูล และไม่บันทึกเนื้อหาข้อความลง log
- เซิร์ฟเวอร์เก็บเฉพาะ SHA-256 ของกุญแจ ไม่เก็บกุญแจจริง
- ข้อความที่ผู้ใช้ส่งจะถูกส่งไปตรวจกับ OpenAI Moderation API ก่อนแสดงผล
- โพสที่หมดอายุถูกลบจริงจากฐานข้อมูล
